# Rancangan S1 — oracle argv byte-for-byte

F0-B baru setelah gate DEC-003 sebagaimana diamandemen [DEC-009](../../plans/baseline-v3.md#dec-009--amandemen-governance-review): review kontrak terintegrasi SELF berbasis evidence, penyelesaian blocker material, penerimaan F0-A dan otorisasi scope pemilik. LLM-ADV opsional. Tidak menjalankan S1 dalam A4.

- Build inert C17 dumper pada disposable lab: satu executable absolut terverifikasi, hanya menulis record stdout. Tidak membuka file, socket, shell, environment, tidak menjalankan command target; exit nonzero pada write error. Format little-endian u32 argc (termasuk argv[0]), lalu u32 byte_length + byte argv untuk tiap arg. Checked bounds (argc <=33, token <=1024, total <= 32768 raw), write exact, no trailing bytes. Tidak ada interpreter. Harness independent decoder membandingkan bytes input persis, termasuk argv[0], empty, NFD dan apostrof.
- Test harness terpisah; only allowlisted inert dumper. Tidak pernah meneruskan model/produk command atau recipe nyata ke shell. Buat fixture temporary dir, clean environment allowlist, absolute pinned Bash/dash, catat version, digest, locale, VM/container, CPU, toolchain. Run shell noninteractive dengan arg -c yang berisi hanya output renderer yang telah disaring untuk dummy recipe; Bash --noprofile --norc --posix, dash tanpa ENV. Tidak menggunakan eval atau shell=True pada harness. stdin closed, stdout+stderr bounded 64KiB, wall clock <=5s, process tree cleanup; isolasi dan before/after check. Shell/dumper saja di allowlist instrumentation; unexpected exec/file mutation/network -> FAIL. Jangan menganggap harness ini containment F5. Jika lingkungan tidak membuktikan safety, S1 BLOCKED.
- Generator fixed seed (usulan 20261124), PRNG/version direkam, minimal 10.000 generated vectors **per shell** di luar fixed gold; distribution dipraregistrasi sebelum run: accepted 7000 literal safe cases dengan apostrophe/space/glob/substitution-like text/Unicode/leading dash sesuai fixture recipe, rejected 3000 control/UTF8 invalid/unknown shell/unsafe operand/untrusted binding/length. Gunakan raw bytes corpus untuk invalid UTF-8; never hand rejected strings to shell. Pastikan unique test IDs dan denominators; duplicates/missing/timeout gagal, tidak disaring setelah melihat hasil. Edge cases tersendiri. Rekam accepted/rejected count, attempted vs expected, seed dan reproduksi minimal.
- Oracle 1: expected renderer decision dari corpus grammar/independent literal classification; reject wajib tanpa command field dan tanpa canary. Oracle 2: accepted actual shell argv binary decoded; byte equality, exact record framing, exit code, zero unexpected output/execution. Trace instrumentation (execve/execveat, network, side effects) dicatat; tidak mengeksekusi target command. Error/paste/terminal tests termasuk C0/C1, bidi, diagnostics canary dan unsupported profile. Jangan menghitung rejected case sebagai shell invocation sukses.
- Oracle semantik terpisah: curated bilingual intent -> typed slots -> resolved recipe/effects/scope/preview/structured expected; explicit equivalence cases and denied operands. Tidak memakai generator renderer sebagai gold compiler oracle. S1 pass hanya zero mismatch dan zero unintended command, C-05/C-07 masih memerlukan integrasi produk dan canary regression.
- Report SHA/fixture hash, shell/dumper digest, command and environment, counts and every failure, trace limits, reviewer SELF/LLM-ADV, decision. No PASS bila not run, tidak ada tuning threshold setelah hasil.

S1 dapat dikerjakan oleh GitHub Actions pada inert lab yang memenuhi preflight atau disposable VM sesuai scope yang disetujui. Tidak memerlukan Codex desktop untuk A4 ini.
