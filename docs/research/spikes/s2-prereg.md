# S2 — baseline development preregistration
32 reference examples (4/intent, ID/EN) and 100 dev cases: 80 supported (10/intent), 10 ambiguity, 10 OOD. All original synthetic SELF, not human gold, no external text, no blind/production data. Exact duplicate IDs and utterances rejected; semantic independence not guaranteed, templates deliberately visible to implementer; report exploratory bias. Frozen corpus and thresholds at commit, no tuning during run. B0 regex intent ranking, B1 word+char trigram TF-IDF on references only, shared literal slot parser (no neural training). Score intent, full prototype slot joint match, coverage, selective accuracy, ambiguity/OOD, error IDs and confusion. No actual IR stages, resolver authority, policy/renderer or claim JS/PSS/FES. Fixed synthetic end time, numeric range, explicit fixture path (no filesystem access), preserve path/unit text; prototype semantic limitations. Every failed/abstained supported case counts; no performance gate. 20 warm passes (2000 requests), p50/p95, first pass and process peak RSS (shared Python process, not isolated model memory), Debian userspace on CI not reference VM. Record CPU. B0/B1 can fail; retain results and use errors for next iteration, not blind tuning. No network or command execution from algorithm. No F0-C acceptance.
