# ADR 0004 — F0-C structured walking skeleton

Scope [#23](https://github.com/megaalive/ai-lab-dictum/issues/23), baseline v3 + DEC-009.
No host-equivalence, VM attestation, executor, training, real OS results or F1.

- B0 complete bilingual grammar matches bounded tokens, not substring intent detection; quoted literals are preserved by byte span. Optional limit/depth grammar is bounded. B1 guarded word-overlap ranking on pinned 32 S2 references uses the same NLUProposal interface and cannot bypass grammar or introduce authority. B1 is experimental and not a replacement for B0.
- A separate immutable in-process synthetic request snapshot records exact input SHA-256, reference UTC, source/policy/profile hashes, sequence and optional time candidate. Relative windows resolve before NLU; the context-ref refers to that candidate. IDs are domain-separated deterministic fixture identifiers, unique by stage within a request; not session IDs, not random credentials, no persistent or cross-process use, no boot-time freshness claim.
- The generator verifies exact source Git blob pins; the scope fixture itself is authored development material. Debian profile remains NOT VERIFIED/BLOCKED, never release trust. Approved roots, units, and literal filters are exact synthetic strings, not descriptor/identity checks on the host. No filesystem is accessed. Policy rejects unknown targets, traversal, sensitivity outside allowlist and invalid slots, rechecks typed values. F0-C requires explicit port even though catalog permits protocol-only. Missing/duplicate slots clarify, unsupported grammar abstains.
- Every NLU, ResolvedIR, PolicyDecision and allowed structured ExecutionPlan passes native schema; plan digest uses actual JCS and SHA-256; renderer checks the immutable plan against recomputation. Independent Python oracle rechecks semantic relations and actual digest/context snapshot. This does not validate malicious external serialized stage ingestion (none is exposed).
- All eight narrative-only handlers are pinned structured-proposal IDs with no dispatch implementation. Effect metadata describes intended operation, not actual effects. No utility identity, argv, shell command, target execution or access. CLI emits only structured view; never prints NLU/context/plan or raw errors. Probe is development-only. Runtime contains no neural model.
- CLI ask/explain stateless, search exact canonical ID, inspect static identifiers; no history/persistence. Relative times use UTC epoch reference, not inferred time zone; absolute date/time and unsupported grammar abstain. No general language coverage or blind quality claim.
- C-05 must independently test inert quoting only; all actual product views remain non-copyable until a later verified binding. C-06/C-07 require actual CLI trace and canary tests. C-09 reports actual development baseline, not F2/F3 gate; S3, FES and F0-D/F1 remain blocked/hold.
