## DCT008-BUILD — Compile, link, CTest, dan sanitizer

```sh
for compiler in gcc clang; do
    for type in Release Debug; do
        sanitizers=OFF
        if [ "$type" = Debug ]; then sanitizers=ON; fi
        build="/audit-final/build/$compiler-$type"
        CC="$compiler" cmake -S /audit-final/src -B "$build" \
            -DCMAKE_BUILD_TYPE="$type" -DCMAKE_COMPILE_WARNING_AS_ERROR=ON \
            -DDICTUM_ENABLE_ASAN="$sanitizers" -DDICTUM_ENABLE_UBSAN="$sanitizers"
        cmake --build "$build" --parallel 2 --verbose
        ctest --test-dir "$build" --output-on-failure --no-tests=error
        sha256sum "$build/dictum"
    done
done
```

Kedua unit C dibangun dengan `-std=c17` dan `-Werror`. Build Debug
memakai `-fsanitize=address,undefined` saat compile dan link, tanpa temuan
sanitizer di suite. Build Release memakai konfigurasi sanitizer `OFF`.

## DCT008-A02 — Trace proses, jaringan, dan kanal keluaran

Pada dua ELF Release DCT008-B01/B03, jalankan pola berikut untuk setiap baris
tabel. `bin` adalah path absolut executable, `prefix` adalah
`/audit-final/logs/trace/<compiler>-<kasus>`, dan `"$@"` meneruskan token
literal dari tabel.

```sh
status=0
env -i LC_ALL=C.UTF-8 /usr/bin/strace -f -yy -s 160 \
    -e trace=%process,%network,%ipc,write,writev -o "$prefix.strace" -- "$bin" "$@" \
    </dev/null >"$prefix.stdout" 2>"$prefix.stderr" || status=$?
```

| Kasus | Token setelah executable | Exit / kanal yang diharapkan dan teramati |
| --- | --- | --- |
| `help` | `--help` | `0` / stdout |
| `version` | `--version` | `0` / stdout |
| `no-args` | Kosong | `2` / stderr |
| `unknown` | `--help-DCT008_CANARY` | `2` / stderr |
| `ask-empty` | `ask ""` | `2` / stderr |
| `ask-missing` | `ask` | `2` / stderr |
| `ask-extra` | `ask siapa yang` | `2` / stderr |
| `ask` | `ask "siapa yang menggunakan port 5432?"` | `3` / stderr |
| `ask-canary` | `ask` dan satu argumen dari `printf 'DCT008_CANARY %%s; \033[31m\nakhir'` | `3` / stderr |
| `run` | `run "siapa yang menggunakan port 5432?"` | `4` / stderr |
| `run-extra` | `run --version DCT008_CANARY` | `4` / stderr |

**Harapan.** Satu `execve` awal ke ELF, tanpa `execve` atau `execveat`
tambahan, pembuatan proses, aktivitas jaringan, atau IPC yang tertangkap.
**Aktual — PASS.** Pada 22 peluncuran, pemeriksaan jejak mengizinkan satu
`execve` awal sukses, penulisan ke berkas keluaran yang diharapkan, dan
terminasi dengan status yang benar. Tidak ada panggilan lain dalam filter
tersebut atau pantulan canary ke kedua stream. Jejak peluncuran sendiri
merekam argumen sintetis yang diteruskan harness.

**Cakupan.** Hasil terbatas pada kedua ELF, input sintetis, bersihnya
environment, deskriptor yang diarahkan ke berkas, dan filter tracer di atas.
Perilaku ketika pemanggil mewariskan socket sebagai stream atau menyuntikkan
kode ke loader berada di luar probe. Ulangi audit dan trace bila jalur
produk atau dependensi berubah.

oleh harness dipakai untuk pemeriksaan argv, terpisah dari hitungan
spawn produk DCT008-A02. Terminasi karena SIGPIPE berstatus **NOT RUN**.
