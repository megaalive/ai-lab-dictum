# B2 lightweight linear baseline — development mechanics

Ref #40 / #28 / #35. **Actual synthetic B2 fit and evaluation completed under DEC-011** (see [results](evidence/f1-synthetic-first-results-v1.json)). Private human gold and external corpus rights remain separate prerequisites for those inputs, not for the approved original synthetic path. The initial mechanics did not read a text corpus. The follow-up research-only integration and private candidate/lock workflow are described in [F1 private development workflow](f1-private-development-workflow.md); no product pack loader or CLI B2 mode is added.

The baseline mechanics are fixed: 48 canonical ordinal classes (index = ordinal minus one), 1024 binary feature bins, FNV-1a 32-bit hash of byte word runs, ASCII case folding only, punctuation separators (non-ASCII UTF-8 bytes retained as part of words), no Unicode linguistic normalization. Sorted nonoverlapping authoritative byte spans mask complete intersecting word runs; exact input UTF-8 and scalar boundaries required. Hash collisions and unknown language coverage are limitations, not semantic evidence. Native and Python implementations use binary features, int16 weights and bias, int64 exact accumulation, deterministic abstention on ties, empty features or inadequate positive integer margin. Margin is not a calibrated confidence. Numeric multiclass perceptron fitting is deterministic for a fixed input ordering, seed and epochs, saturates weights, and has bounded numeric rows/epochs. Mechanical parity tests use abstract numeric rows and fixed synthetic weights. The DEC-011 experiment actually fits the separate project-original synthetic train split.

The actual F1 comparator uses either an independently reviewed, rights-approved private corpus or the DEC-011 project-original synthetic path, with frozen train/dev/test membership and stated grouping protocol. No repository F0/F1/S2 regression vectors, blind labels, or test-derived thresholds may enter training. Lock exact source hashes, preprocessing and features, labels, seed(s), epoch/compute limits, class coverage and margin selection on dev only, then evaluate once on the locked test. Report raw classifier and end-to-end separately on the common preregistered denominator, resource/latency and misses. The same native deterministic extractor must mask its resolved input spans; a classifier match cannot introduce a slot, override scope or negative outcomes, or authorize a plan. Common-extractor integration is now implemented in a separate research executable; fixed-weight and guard-transition tests are not actual classifier accuracy. The first actual synthetic fit/evaluation is complete; quality is inadequate, private human corpus and blind evaluation remain pending. No generalization, release-model trust or F2 claim follows from numeric parity. The library is linked only into development probes, not the product CLI. B0/B1 product behavior remains unchanged.

A shape-valid manifest cannot authorize data usage. DEC-011 authorizes the exact project-original synthetic scope; external/private corpus rights and human review must still be genuine. Preserve holdout isolation and do not upload private records or weights to GitHub without explicit approval.
