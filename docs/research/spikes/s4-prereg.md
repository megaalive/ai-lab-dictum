# S4 — prereg numerik sintetis
Scope F0-B, no training, no native model loader. Float binary32 operands, reference Python rounds each product and addition through struct; no FMA, C17 -ffp-contract=off -fno-fast-math. Quantization prototype symmetric per-row, scale positive finite, binary32 values promoted to binary64 ratio, nearest ties-to-even, saturate [-127,127] (DCTM signed I8 format may represent -128; this quantizer doesn't emit it), no nonfinite input. Exact int32 accum with widened checked add at every step; boundary checks. Compare fixed golden quant values, nonfinite/scale rejects, exact int accum, FP32 Python vs C and INT8 Python vs C dequantized logits separately (not FP32 vs INT8 quality). atol 1e-3, rtol 1e-4 provisional before run; max abs/relative and exact top selection (ties lowest class ID, near ties not collapsed). No full architecture parity. Candidate M1 config enumerates all tensor shapes for vocab4096/context128/d_model128/4 layers/FF512/4 heads, 48 intent and illustrative 21 BIO labels; count actual shape arithmetic but no instantiated model. Bias/norm/position/heads included; no tied weights; payload estimates exclude metadata/scale/alignment/activations. CI GCC/Clang CPU only. This is operator feasibility, not product gate or claim of resource performance.
