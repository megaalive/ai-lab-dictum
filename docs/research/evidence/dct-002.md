## DCT002-NATIVE — Regresi DCT-008

```sh
work=/dct002/5a2525d7999c61b4614364bc694d086bb6b862eb
for compiler in gcc clang; do
    for type in Release Debug; do
        sanitizers=OFF
        if [ "$type" = Debug ]; then sanitizers=ON; fi
        build="$work/build/$compiler-$type"
        CC="$compiler" cmake -S "$work/src" -B "$build" \
            -DCMAKE_BUILD_TYPE="$type" -DCMAKE_COMPILE_WARNING_AS_ERROR=ON \
            -DDICTUM_ENABLE_ASAN="$sanitizers" -DDICTUM_ENABLE_UBSAN="$sanitizers"
        cmake --build "$build" --parallel 2 --verbose
        ctest --test-dir "$build" --output-on-failure --no-tests=error
    done
done
```

**Harapan.** Target native tetap dibangun dengan toolchain C17. Regresi
16 kasus CLI lulus pada setiap konfigurasi.
**Aktual — PASS.** GCC/Clang Release dan Debug ASan+UBSan masing-masing
lulus 16/16, dengan `-std=c17` dan `-Werror`. CMake, sumber native,
serta fixture dan harness CLI identik dengan base.

