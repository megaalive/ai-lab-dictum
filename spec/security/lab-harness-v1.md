## Preflight (human operator + independent lab controller evidence)

All checks required before **any** target operation. State VERIFIED only with actual evidence hash/ref, operator and SHA; unknown/failed/missing -> BLOCKED, no target execution. Machine record/validator is checklist lint, not proof. Do not self-certify isolation from JSON. Record:
1. Owner authorization exact scope and command/handler allowlist, source SHA, profile; disposable VM identity and clean baseline snapshot, not production/management host; CPU/kernel and guest resources.
2. No shared folder/host mount, clipboard, host credential/SSH agent/token or USB passthrough; no bridge to production or management VLAN; egress blocked at hypervisor/firewall including IPv4/IPv6 and DNS, no route/proxy/forwarding; verify inherited FD/socket and AF_UNIX/daemon proxy risk. No network probe to real hosts to test.
3. Exact fixture root descriptor, synthetic data, target identity and reset method; before/after allowlisted state manifest, canaries, no access to real data. VM snapshots don't prove anti-replay; trusted reset/session after restore.
4. Verify UID/GID/capability/namespace and required primitive support; no new sudo/groups; no arbitrary raw shell or interpreter; approved command/handler IDs and exact argv grammar pinned. Service/log in S3 only explicitly authorized disposable fixtures; no product eligibility. No NET/CHANGE operation target in S3 without separate baseline scope (baseline S3 read-only). Document host-equivalence oracle on same lab host/namespace, expected permission/scope/visibility/output; not production data.
5. Verified resource containment: cgroup v2 delegation, atomic placement before execution (clone3 CLONE_INTO_CGROUP or proof stop-before-untrusted-code), no migration, limits CPU/memory/pids, rlimits, deadline monotonic 5s, output 65536 combined stdout/stderr, nonblocking read, overflow termination, cancellation, tree kill verify empty/drain/reap. If primitive or isolation unavailable -> S3 BLOCKED, no fallback. Landlock ABI/features or confinement alternative assessed and tested; seccomp/NNP/nonroot, path/FD and network restrictions; not claim complete sandbox.
6. Verified independent lab runner/controller separate from CLI, before/after compare and expected oracle, clean reset per case; collect trace of execve/execveat/socket/IPC/filesystem and unexpected effects subject to instrumentation limits. Any unknown, unexpected effect, failed reset, uncontained process -> stop whole run; quarantine VM, preserve sanitized logs and revoke session; do not count as success.
