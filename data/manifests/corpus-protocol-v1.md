Tidak ada training, blind benchmark, atau import dataset pada A7. Data sintetis-only dalam repo, tidak memakai data nyata/sensitif, command output nyata, log pasien, hostname/path internal, history, kredensial, atau identitas manusia. ## Provenance dan hak

Ledger machine-readable [license-ledger-v1.json](license-ledger-v1.json) mencatat per sumber: URI, artifact role/version, exact content identity/hash dan jenis hash, source/license/attribution, derivation, allowed use, distribution decision/status. Status UNKNOWN/NOT VERIFIED tidak berarti hak diberikan; exclude dari distributable corpus/catalog dan training sampai audit. Referensi kandidat tanpa versi/hash tidak diunduh atau disalin dalam A7. Hak teks, anotasi, code, model/weights, output teacher dan derivasi dievaluasi terpisah, termasuk upstream dependencies. Jangan berasumsi lisensi repo berlaku untuk data/weights. S5 memeriksa terms actual dan atribusi per source/version/file; owner menyetujui keputusan lisensi/distribusi. Jika hak tidak jelas, hanya referensi internal yang diizinkan sesuai terms, tanpa copy/training/distribution; tidak menganggap izin internal otomatis. Ledger awal mencatat Git blob internal yang memang tersedia; Git SHA hanya identity bukan trust. Pin SHA-256 byte artefak nyata sebelum penggunaan release. Tidak menentukan lisensi bobot atau memindahkan ownership.

Setiap record masa depan: opaque case_id unique, language id/en/mixed (dominant_language bila mixed), exact raw UTF-8 text bytes/hash, normalized key (untuk grouping/dedupe saja, bukan mengganti literal slot), intent ID atau unsupported, typed slot candidates + original byte spans/candidate refs, context/profile/catalog version/hash, expected resolution/policy, semantic group ID, template family ID, source ID/version/hash, derivation/parent IDs, generator/teacher ID/version/prompt hash/seed (null jika authored manusia), review identity/label and status, fixture ID dan oracle version. Ambiguity/OOD/unsafe/security tags terpisah; label jangan disalin dari generator sebagai gold. Reject unknown source, invalid bytes/IR/slot spans, ambiguity tak terselesaikan dalam supported, data sensitif, rights unknown, duplicate case ID; catat reason tanpa secret. Tidak membuat command bebas sebagai ground truth. Preserve raw path/Unicode byte identity.

## Urutan konstruksi dan split

1. Bekukan canonical registry 48 intent dan data protocol; tulis semantic group (intent + scenario + target/time/negation/constraints/fixture) serta template family sebelum augmentasi. Seed manusia 200–500 untuk development F1; 8 skeleton terlebih dahulu pada F0-C. Gold seluruhnya human-reviewed; disagreement adjudicated, CHANGE/NET gold wajib review manusia; teacher membantu parafrasa, bukan oracle.
2. Exact normalized utterance + canonical IR/fixture grouping, near duplicate/fuzzy candidates via token/character Jaccard/MinHash, parent/template lineage. Bentuk connected groups termasuk semua near-miss sibling dan translations; tidak memecah satu group/family across splits. Human review false grouping. Jangan menghapus hard cases setelah hasil model terlihat.
3. Split deterministic by group/family, bukan individual record, sebelum augmentasi. Target train/dev/test development 70/15/15; stratify intent/language without breaking groups, report deviations/counts and split seed 20261124; lock assignment manifest (hash, generation version, group IDs, source ledger). Semua paraphrase/augmentation mengikuti split parent; cross-split duplicate/family/parent reject; contamination -> quarantine and regenerate split, document. Target language ~70% id / 30% en untuk development corpus, mixed dilaporkan terpisah; denominator pure-language N_id+N_en, target tidak memaksa label/gold atau memecah group. Report by intent and language including mixed; no posthoc quota tuning on holdout.
4. Known-intent train/dev/test berbagi 48 intent, hold out semantic groups. Compositional holdout menahan kombinasi slot/target/family yang didefinisikan sebelum augmentasi, bukan intent label yang hilang. Unseen-intent experiment terpisah: exclude held intent dari train dan classifier head, retrieval dengan katalog baru atau zero-shot, explicit known-to-model; tidak campur ke known-intent gate. OS/version cross-distro deferred F7.
5. Tokenizer, retrieval examples/index, normalization learning dan thresholds hanya train (dev untuk tuning) + katalog terverifikasi yang diizinkan. Blind holdout manusia terpisah dari train/dev/test, generator prompts, retrieval dan owner/operator training access. Holdout disimpan di luar repo publik dan artefak training; independent custodian/authorized evaluator holds gold and access key. Lock exact manifest/version/hash, predeclare denominator, groups and labels, encrypt/access-controlled store, append-only access log (time, actor role, purpose, artifact digest, action, decision, no raw text). Record any read/export. Trainer receives only aggregate final metrics/error categories after one preregistered run; no labels/individual cases used for tuning. Leak or unauthorized access -> invalidate holdout, record incident, new human-reviewed holdout with new prereg; not rescore until locked. No invented EXT review; evaluator role alone not independent.
6. Before corpus use, automated schema + IR and semantic human audits, exact/fuzzy/lineage cross-split checks, license status and source snapshot pins, audit sampled distributions, acceptance/reject reason and agreement. All gold, risky CHANGE/NET, disputed cases reviewed. Semantic gold evaluates negation, target, scope, time, units, cardinality, effects, safe clarification/denial separately. Raw gold cannot come from model generator alone. C-01/C-02 functional gold and S2 dev examples not blind quality claims.
