# ADR 0002 — Broker, approval dan executor terpisah

Status: accepted as F0 design candidate, implementation DEFERRED-BLOCKED F5. Scope baseline §5.1b, §9, §9.1. No broker/service/product executor in F0–F4.

## Decision

Front (model, retrieval, parser/CLI) untrusted; never receives consent key or authority endpoint access. Broker small trusted process owns immutable request records, validated catalogue/policy/currentness, action IDs, scope and target handles. It re-resolves or independently validates every typed candidate against trusted state; no untrusted effect/privilege/digest/approval from Front. Trusted Approval separate UI/input/transport receives canonical plan and warnings directly from Broker, renders independently using reviewed deterministic representation, human confirms exact action; Front cannot control prompt/input/response or fake approval. Executor accepts only authenticated Broker dispatch, not Front requests. Distinct UID/process isolation, restrictive socket endpoints/LSM, protected proc/ptrace/signal/FD/terminal paths and minimal capabilities required. Same UID or peer cred alone insufficient; any unresolved human-path gap blocks F5.

Alternatives rejected: run shell string/eval; direct CLI spawn even typed argv; same-process approval flag; user clicking Front-controlled text; broad sudo helper. Memory-safe broker implementation can be chosen later by ADR after TCB analysis; C17 runtime model remains separate. No helper privilege granted by this ADR.

## IPC candidate (F5 design)

Unix SOCK_SEQPACKET local, authenticated endpoint owned by trusted service (no abstract/world-writable socket; directory/socket identity and ownership verified). Fixed 32-byte little-endian header parsed fieldwise: magic 4 'DCTI', major u16=1, minor u16=0, opcode u16, flags u16=0, payload_len u32, sequence u64 (positive monotonic per session), reserved u64=0. Header+payload <=32800 bytes; payload <=32768, exactly one packet, strict versioned closed typed payload, no arbitrary strings/executable from Front authority. Separate channels and roles, no fallback to stream or shell. Receive with bounded buffer, MSG_CMSG_CLOEXEC where supported, reject MSG_TRUNC/MSG_CTRUNC, short/long frame, unknown version/opcode/flags/reserved, malformed payload, replay/out-of-order, stale policy, mismatch peer/endpoint/session. Close unexpected/surplus ancillary FDs on every path including reject; never trust received file path. Default FD count zero; only explicitly reviewed future op for exact descriptor roles may carry count/type/ownership/identity, fstat and verified seal/flags; reject unknown cmsg/SCM_RIGHTS count/type, check close-on-exec, never pass inherited sensitive FDs. FD identity is not authorization or immutability. Kernel credentials verified (SO_PEERCRED, peer identity + endpoint/session), not consent; establish fresh session with unpredictable nonce from OS CSPRNG and channel-bound role, no reusable cross-session sequence.

Opcode outline (not wire implementation): Front channel HELLO, SUBMIT_TYPED, CANCEL, STATUS; Broker returns bounded PLAN_SUMMARY/TERMINAL. Approval channel separate CHALLENGE, HUMAN_DECISION; Executor channel DISPATCH_BOUND_PLAN, RESULT, CANCEL. Opcode registry and complete message schemas frozen only after F5 review; do not send or accept production messages now. Front cannot send HUMAN_DECISION or DISPATCH_BOUND_PLAN on any channel. Unknown op -> close/deny. Session restart/reconnect revokes all challenges and pending dispatch. No privileged helper until exact action and IPC/FD protocol independently reviewed.

## Consent binding and lifecycle

Broker builds immutable plan (IR v1 execution-candidate only under future F5 eligibility). Canonical plan digest JCS + domain separator per DCT-002, recompute from same snapshot. Consent envelope (separate future protocol, not modification IR) binds canonical plan digest and action/request IDs, executable path/digest/version or native handler, ordered typed argv, exact target/cwd handle identities, scope, effect, UID/GID/capability, verified context/catalog/policy/model digests, runtime constraints, session/boot, CLOCK_BOOTTIME expiry, random single-use 128-bit+ nonce. Canonical encoding and field types finalized F5 with golden vectors; unambiguous domain separation, no concatenation ambiguities. Broker maintains server-side challenge state or MAC with secret session key; approval channel authenticated, no raw model approval. Digest alone not MAC/signature. Trusted UI shows exact plan and warnings, handles may not be replaced after display. Default 30s TTL after challenge, hard <=120s and <= context expiry; no extension without new challenge. Reject clock failure, expired, revoked, policy/context/identity/permission changes, replay, terminal or scope mismatch. Consume exactly once atomically before any spawn/dispatch, even failure; revalidate immediately before execute against same handles and policy, no silent retry. Cancel/revoke atomically with dispatch (race cases tested); after dispatch cancellation terminates contained tree, not retroactive effect undo. Restart/reconnect/boot/restore/suspend detected or trust state invalid -> invalidate all nonces/session, require trusted reset. Host privileged snapshot rollback outside guarantee absent independent monotonic anchor; disable after detected restore. 

State transitions: proposed -> independently eligible -> challenged -> human approved -> consumed -> dispatched -> terminal. Denied/expired/revoked terminal from pre-dispatch, no back edge; policy eligibility is not approval. Failure before dispatch consumes or revokes nonce, not reusable. Concurrent approvals/cancel races require atomic test proof. Neither S1 nor S3 grants authority to this future flow.

## Containment obligations

Verified executable descriptor and loader/library trust; immutable handles, explicit local scope, no path-based reopen race. Drop capabilities/nonroot/no_new_privs, descriptor hygiene, environment/cwd allowlist; per-intent syscall, filesystem and IPC/net policies; Landlock verified ABI or mount namespace + descriptor binding + seccomp; deny when primitives unavailable; no raw shell/interpreter. cgroup v2 atomic placement before untrusted code, no migration, bounded CPU/RAM/pids, rlimit FD/AS/etc where suitable, wall 5s, total output 64KiB nonblocking, overflow terminate, kill all cgroup and verify empty/drain/reap; process group supplementary only. No production bridge/egress; deny daemon proxy; test visibility host-equivalence separately. NET, CHANGE, diagnosis, service/log never execute in MVP. No product F5 without EXT human security reviewer + owner approval; specification status DEFERRED-BLOCKED.

## Validation

F5 tests: strict parser fuzz including malformed lengths/FD truncation/opcode/replay/peer mismatches; endpoint impersonation, compromised Front, fake UI/terminal, ptrace/proc/FD theft, cross-session/boot/context, wrong digest/changed argv/target, duplicate nonce, expiry/cancel race, restore; containment, egress, resource/fork/orphan, secret canaries, host-equivalence for each binding. All NOT RUN. This ADR chooses boundaries and proof obligations; it does not implement protocol or certify any control.
