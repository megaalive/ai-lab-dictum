# ADR 0008 — Versioned proposal-only IR v2 and all 48 intents

Ref #38. V1 schema/registry/profile/gold files retained byte-identical. Product emits closed v2 NLU, resolution, policy and structured plan (only when allowed), with v2 catalog/policy identities. Effective catalog overlay pins base registry, profile and reviewed deferred-domain contract; no cast of new values into v1. Eleven new kinds and DNS A default are explicit. V2 rejects execution-candidate and executable action; v1 validators remain for historical fixtures, not used to ingest product requests. V2 digest domain differs; a digest is not authorization. Scope remains exact synthetic values. No host operation, utility invocation, actual file read/write, DNS or ICMP, model pack loading or privilege. All real bindings blocked. Product diagnoses emit fixed bounded narrative guidance without plan/handler/child operation or raw target projection. Help summaries are original internal fixture metadata, not imported manuals or verified utility semantics. Archive proposal checks explicit source and new synthetic destination, rejects equal/nested/known identities; does not attest real destination absence or safe extraction. DNS/ping explicitly NET non-copyable, no traffic. No raw execution syntax or automatic actions.

Generalization: whole-utterance grammar, bounded polite prefix/suffix and compositional named suffix slots; exact typed literal semantics and byte-span provenance unchanged. B1 weighted distinct lexical matches over pinned 112 references and original catalog descriptions, excluding fixed common terms and explicit slots, inverse intent document frequency; no tuning to S2 labels, no grammar bypass, deterministic ties abstain. Safety and clarification preflight before ranking. B0 primary, B1 diagnostic. Additional 202 SELF functional cases include 90 supported across remaining 15 intent IDs + 12 compositional cases; predecessor suites and S2 unchanged. Indonesian/English authored phrases remain narrow; some domain literal enums require exact English first/last or canonical A; no human gold or broad language-quality claim. Actual native differential, semantic mutation tests, strict sanitizer and isolated CLI trace required. Human seed rights, actual training, blind holdout, reference VM, host-equivalence, FES and F2 not authorized or run. S3/executor stay blocked.
